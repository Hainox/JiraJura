# Видео-инструкция: Роль Проверяющего (Reviewer)
## Журнал обхода площадок САО — JiraJura

> Длительность: 8–10 минут
> Формат: скринкаст (запись экрана) + голос за кадром
> Стиль: спокойный, деловой, с акцентом на ключевые моменты

---

## СЦЕНА 1 — Вход в систему (0:00–0:40)

**Кадр:** Открыт браузер, адресная строка: `https://jirajura.ru`

**Голос:** «Здравствуйте. Это инструкция для проверяющего в системе "Журнал обхода площадок САО". Проверяющий — это сотрудник, который контролирует качество обходов, проведённых инспекторами в закреплённом районе.»

**Действие:**
1. Вводим логин (например, `AndreevaNV`)
2. Вводим пароль
3. Нажимаем «Войти»

**Голос:** «После входа вы попадаете на главную страницу — карту вашего района. Проверяющий видит только площадки своего района. Администратор назначает район при создании учётной записи.»

**Кадр:** Главная страница с картой. В шапке видно: «Андреева Надежда Валерьевна (проверяющий)».

---

## СЦЕНА 2 — Карта и навигация (0:40–1:30)

**Кадр:** Крупно — шапка с кнопками.

**Голос:** «В верхней панели — инструменты проверяющего. Разберём слева направо.»

**Действие:** Поочерёдно наводим курсор на каждую кнопку:

| Кнопка | Назначение |
|--------|-----------|
| 📊 (BarChart) | **Дашборд** — сводная статистика |
| ⚠ (AlertCircle) | **Замечания** — управление замечаниями |
| 📥 (Download) | **Excel-выгрузка** — скачать отчёт |
| 🔽 (Фильтр) | **Фильтры** — по району и типу площадок |
| ☀️/🌙 | **Тёмная тема** — переключить оформление |
| 👤 (UserCircle) | **Профиль** — изменить свои данные |
| 🚪 (LogOut) | **Выход** |

**Голос:** «Три основные вкладки: Карта, Список и Проверка. Остановимся на каждой.»

---

## СЦЕНА 3 — Режим «Проверка» — очередь обходов (1:30–3:00)

**Кадр:** Переключаемся на вкладку «Проверка» (жёлтая кнопка с иконкой).

**Голос:** «Вкладка "Проверка" — ваш главный рабочий инструмент. Здесь отображаются все обходы в вашем районе.»

**Действие:**
1. Показываем фильтры статусов: «Все», «На проверку», «Принятые», «С нарушениями», «Критические»
2. Кликаем «На проверку» — показываем обходы, ожидающие проверки

**Голос:** «Фильтры помогают быстро найти нужные обходы. Например, "На проверку" — это обходы, завершённые инспектором, но ещё не проверенные. Каждая карточка обхода содержит:»
- ✅/⚠/🕐 — иконка статуса
- Название площадки и район
- Имя инспектора и дата обхода
- Счётчики: ✓ ОК, ✕ нарушений, 📷 фото, ⚠ замечаний
- Плашка «✓ Проверен» с именем — если обход уже проверен

**Голос:** «Нажмите на карточку обхода, чтобы открыть его для проверки.»

**Действие:** Кликаем на карточку — открывается страница обхода.

---

## СЦЕНА 4 — Проверка обхода (3:00–5:30)

**Кадр:** Страница обхода в режиме чтения (read-only для проверяющего).

**Голос:** «Вы видите полный обход. Проверяющий не может редактировать ответы инспектора — только просматривать. Что доступно:»

**Действие:**
1. **Пролистываем чек-лист** — показываем зелёные ✓ ОК и красные ✕ Нарушения
2. **Раскрываем фото** — кнопка 📷 в шапке показывает общие фото площадки
3. **Смотрим фото дефектов** — миниатюры под каждым пунктом с нарушением
4. **Читаем комментарии инспектора** — текстовые поля под пунктами

**Голос:** «Для каждого пункта с нарушением инспектор прикладывает фото дефекта. Вы можете кликнуть на миниатюру, чтобы открыть фото в полном размере.»

**Действие:** Кликаем на фото — открывается в новой вкладке.

---

## СЦЕНА 5 — Панель «Проверить» (5:30–7:00)

**Кадр:** Нажимаем кнопку «Проверить» в шапке обхода. Открывается панель проверки.

**Голос:** «Кнопка "Проверить" открывает панель с вариантами решения. Вы можете:»

**Действие:**
1. Вводим комментарий: «Всё корректно, нарушений нет»
2. Нажимаем **«✓ Принять»** — обход получает статус «Завершён»

**Голос:** «Зелёная кнопка "Принять" — когда всё в порядке. Оранжевая "Есть нарушения" — когда есть замечания. Красная "Критический" — когда требуется срочное вмешательство.»

**Действие:**
3. Показываем кнопку **«Вернуть на доработку»** (жёлтая, с иконкой ↩)

**Голос:** «Если обход заполнен некачественно — нажмите "Вернуть на доработку". Обязательно напишите комментарий — что именно нужно исправить. Инспектор увидит баннер "Возвращено на доработку" с вашим комментарием и сможет доработать обход.»

**Действие:**
4. Вводим комментарий: «Не приложены фото дефектов по пунктам 3 и 7»
5. Нажимаем «Вернуть на доработку»

**Голос:** «После проверки в обходе фиксируется: кто проверил, когда, с каким результатом. Эта информация видна в очереди проверки — зелёная плашка "✓ Проверен".»

---

## СЦЕНА 6 — Управление замечаниями (7:00–8:30)

**Кадр:** Возвращаемся на главную. Нажимаем ⚠ «Замечания» в шапке.

**Голос:** «Страница "Замечания" — список всех замечаний в вашем районе. Здесь вы можете:»

**Действие:**
1. **Фильтровать:** по статусу (Открыто / В работе / Исправлено), критичности, району
2. **Искать:** поле поиска фильтрует по названию, площадке, району
3. **Редактировать замечание:** кнопка «Изменить» → меняем статус, назначаем ответственного, ставим срок

**Голос:** «Для каждого замечания можно сменить статус — например, "Открыто" → "В работе" → "Исправлено" → "На контроле" → "Закрыто". Также можно назначить ответственного и установить срок исполнения.»

**Действие:**
4. Нажимаем «Изменить» на любом замечании
5. Меняем статус на «В работе»
6. Назначаем ответственного из выпадающего списка
7. Ставим дату срока
8. Нажимаем «Сохранить»

**Голос:** «Иконка 🔗 рядом с замечанием открывает обход, в котором оно было создано — можно быстро перейти и посмотреть контекст.»

---

## СЦЕНА 7 — Дашборд и Excel-отчёт (8:30–9:30)

**Кадр:** Нажимаем 📊 «Дашборд» в шапке.

**Голос:** «Дашборд показывает сводную статистику по вашему району: сколько площадок, обходов за неделю и месяц, сколько на проверке, сколько открытых замечаний. Кнопка "По районам" раскрывает процент охвата — progress-bar'ы по каждому району.»

**Действие:** Нажимаем «По районам» — показываем прогресс-бары.

**Голос:** «Excel-выгрузка — кнопка 📥 в шапке главной страницы. Отчёт содержит 6 листов: сводка, обходы, нарушения по чек-листу, замечания, просроченные замечания и динамика по дням. Удобно для планёрок и отчётности.»

**Действие:** Нажимаем 📥 → скачивается Excel-файл → открываем, показываем листы.

---

## СЦЕНА 8 — Профиль и тёмная тема (9:30–10:00)

**Кадр:** Нажимаем 👤 «Профиль».

**Голос:** «В профиле можно изменить ФИО, телефон и пароль. Кнопка ☀️/🌙 переключает тёмную тему — удобно при слабом освещении.»

**Действие:** Переключаем тему → показываем разницу.

**Голос:** «Это все основные функции для проверяющего. Спасибо за внимание.»

## ТЕХНИЧЕСКИЕ РЕКОМЕНДАЦИИ

- **Разрешение:** 1920×1080 (Full HD)
- **Масштаб браузера:** 100%, без панелей разработчика
- **Аккаунт:** Заранее создайте тестового проверяющего с закреплённым районом (например, `AndreevaNV`)
- **Данные:** Заранее создайте 2–3 тестовых обхода (один с нарушениями, один без)
- **Курсор:** Включите подсветку курсора (например, через OBS или встроенные средства)
- **Микрофон:** Запись в тихом помещении, без фонового шума
