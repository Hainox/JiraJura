# docs/coordination/

Рабочие артефакты асинхронной координации между агентами (Codex CLI,
Claude Code) и владельцем продукта на проекте «Журнал обхода площадок
САО». Протокол, который эти файлы обслуживают, описан в
[`AGENTS.md`](../../AGENTS.md) в корне репозитория — начните оттуда.

- [`STATUS.md`](./STATUS.md) — доска задач (`planned → in_progress →
  review → approved → deployed`) и раздел «Handoff» с заметками между
  сессиями агентов.
- [`DECISIONS.md`](./DECISIONS.md) — append-only журнал значимых
  технических решений: не каждый коммит, а то, что другому агенту иначе
  пришлось бы реконструировать по diff'ам вручную.

Оба файла — рабочие, не архивные: обновляются в ходе задач, не только по
их завершении.
