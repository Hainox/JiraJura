# Routes

## Statistics dashboard

- `/dashboard` → `frontend/src/pages/DashboardPage.tsx`, reviewer-only
- `/admin/dashboard` → `frontend/src/pages/DashboardPage.tsx`, admin-only

The dashboard renders an existing desktop-first data table, period toolbar, and tabs: `Обзор`, `Динамика`, `Категории`, `Обходы`, `Устранение`, `Штаб-отчёт`.
