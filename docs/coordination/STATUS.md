**2026-09-04, Claude Code — свод по участкам (#149):**
- Владелец продукта прислал карту с разбивкой дворов на участки
  (https://hainox.github.io/karta-sao/, `areas.geojson`) и явно
  ограничил задачу: участки — только для внутреннего контроля районов,

  — сам по себе редеплой участки не проставит, миграция добавляет только
  пустую колонку.

  в `areas.geojson` у каждого полигона двора уже есть `district`+`section`

  геометрия у каждой площадки. Единственное расхождение имён районов
  между источниками — «Савеловский»/«Савёловский» (ё/е).
