# Contributing

Правила ниже — и для людей, и для автономных агентов, работающих над этим
репозиторием. Если вы агент (Codex CLI, Claude Code, другой) — сначала
прочитайте [`AGENTS.md`](./AGENTS.md), там протокол координации между
агентами; этот файл — более общие технические правила контрибьюции.

## Настройка окружения

См. [корневой README](./README.md) и [`backend/README.md`](./backend/README.md)
— стек, структура, переменные окружения, запуск через Docker или локально.

## Ветки и коммиты

- Никаких прямых пушей в `main` от агентов — только через ветку и Pull
  Request (у владельца репозитория это ограничение не стоит).
- Имя ветки отражает исполнителя и суть: `claude/...`, `codex/...`,
  `<логин>/...` для людей.
- Коммиты — по-русски, в повествовательном стиле, объясняют, ПОЧЕМУ
  сделано именно так, а не просто описывают diff. Смотрите `git log` —
  стиль уже устоялся, следуйте ему.
- Один PR — одна логически цельная задача. Не смешивать рефактор с
  фиксом бага без явной причины.

## Перед тем как открыть PR

- Backend: `cd backend && pytest -q` — все тесты зелёные. Новая логика —
  новый тест, не просто «работает у меня локально».
- Frontend: `npm run lint && npm run build && npm test -- --run`.
- Миграции Alembic: `alembic upgrade head`, `alembic downgrade -1`, снова
  `alembic upgrade head` — проверить, что откат и повторный накат не падают.
- Секреты, реальные пароли, персональные данные пользователей — не
  коммитить. Если тест требует реалистичные данные — генерировать их в
  самом тесте, не хардкодить настоящие ФИО/телефоны/логины.

## Pull Request

Используйте шаблон `.github/pull_request_template.md`. Секция «Решения и
обоснование» — обязательна для нетривиальных изменений: другой человек
или агент должен понять логику решения, не реконструируя её по diff'у.

## Ревью

Ожидается содержательное ревью, не формальное «approve»: проверка
утверждений из описания PR по реальному коду (не на веру), для миграций —
реальный прогон против тестовой БД. Подробнее про правила ревью между
агентами — в `AGENTS.md`.
