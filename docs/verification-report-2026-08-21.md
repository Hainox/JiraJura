## Что вошло в релиз

### Фото нарушений

- В форму создания замечания добавлена отдельная заметная зона «Фото нарушения».
- Инспектор может выбрать до пяти фотографий, увидеть миниатюры и удалить ошибочно выбранный файл до отправки.
- После создания замечания фотографии загружаются именно в это замечание, а не в общий альбом обхода.
- Если отдельный файл не загрузился, замечание сохраняется, а интерфейс сообщает о необходимости повторной загрузки.
- В подсказке указаны допустимые форматы: JPG, JPEG, PNG, WEBP, HEIC, HEIF, GIF.

### Регистрация

- Ошибка регистрации больше не маскируется сообщением «ссылка могла устареть».
- Пользователь получает понятную причину: занятый логин, недействительная ссылка, ошибка сервера или отсутствие соединения.
- Backend возвращает контролируемый ответ `409`, если логин уже зарегистрирован, вместо необработанной ошибки базы данных.
