# Сценарий видео-инструкции: Журнал обхода площадок САО

## Длительность: ~8–10 минут
## Целевая аудитория: инспекторы и проверяющие

---

## Часть 1: Регистрация (1:00–1:30)

### Кадр 1: Получение приглашения (0:30)
- Показать экран Telegram/почты с сообщением от администратора
- Текст: «Вам придёт ссылка-приглашение от администратора системы»
- Крупно показать ссылку вида `https://journal.yuvibot2.xyz:8443/register/XXXXX`

### Кадр 2: Страница регистрации (0:30)
- Открыть ссылку в браузере
- Показать форму: «Вас пригласили как Инспектор / Проверяющий»
- Ввести пароль (минимум 8 символов)
- Нажать «Зарегистрироваться»
- Автоматический вход → карта площадок

### Кадр 3: Вход при повторном визите (0:15)
- Показать страницу логина: ввести логин и пароль
- Нажать «Войти»

---

## Часть 2: Карта и навигация (1:00)

### Кадр 4: Обзор карты (0:30)
- Показать карту с метками площадок:
  - Синие кружки «Д» — детские площадки
  - Зелёные кружки «С» — спортивные площадки
- Переключение вкладок: Карта / Список
- Фильтры: по району, по типу площадки

### Кадр 5: Карточка площадки (0:30)
- Кликнуть на метку → попап с названием двора, районом, площадью
- Кнопка «Открыть» → страница площадки
- Показать информацию: тип, площадь, адрес
- Кнопка «Начать обход» (если ещё не начат)
- Список предыдущих обходов (если есть)

---

## Часть 3: Проведение обхода (3:00–4:00)

### Кадр 6: Начало обхода (0:20)
- Нажать «Начать обход» на странице площадки
- Автоматически создаётся новый обход со статусом «В процессе»
- Открывается чек-лист

### Кадр 7: Заполнение чек-листа (1:30)
- Показать список пунктов, сгруппированных по категориям:
  - Покрытие, Оборудование, МАФ, Ограждение, Общий вид
- Для каждого пункта два варианта:
  - **✓ ОК** — всё в порядке (зелёная кнопка)
  - **✕ Не ОК** — есть нарушение (красная кнопка)
- Продемонстрировать заполнение 3–4 пунктов
- Прогресс-бар вверху показывает % заполнения

### Кадр 8: Фиксация нарушения с комментарием (0:45)
- Нажать «✕ Не ОК» на пункте «Целостность покрытия»
- Открывается панель внизу:
  - **Написать комментарий**: «Трещина 30 см в районе горки»
  - **Добавить фото дефекта**: нажать «Добавить фото дефекта» → камера → снять
  - Фото появляется под пунктом чек-листа
- **Создать замечание**: нажать кнопку → заголовок «Трещина покрытия» → критичность «Средняя» → отправить

### Кадр 9: Общие фото обхода (0:25)
- Кнопка с иконкой фотоаппарата в шапке
- Панель общих фото: «Добавить общее фото»
- Сделать 2–3 фото площадки общим планом

### Кадр 10: Сохранение и завершение (0:20)
- Кнопка «Сохранить» в шапке — сохраняет все ответы
- Завершить обход можно позже — прогресс не теряется
- Статусы обхода: «В процессе» → «Завершён» / «Есть нарушения» / «Критический»

---

## Часть 4: Проверка и отчёты (1:30)

### Кадр 11: Выгрузка в Excel (0:45)
- Кнопка «Выгрузка в Excel» (иконка скачивания) в шапке карты
- Показать скачанный файл, его структуру:
  - **Лист 1 «Сводка по районам»**: статистика по каждому району
  - **Лист 2 «Обходы»**: все обходы с датами, инспекторами, результатами
  - **Лист 3 «Нарушения по чек-листу»**: детальный список каждого нарушения — что именно, где, кто обнаружил и какой комментарий оставил
  - **Лист 4 «Замечания»**: созданные замечания со статусами
- Объяснить: этот файл — для разбора нарушений на планёрке

### Кадр 12: Фильтры выгрузки (0:20)
- Фильтр по району (для админа)
- Фильтр по датам: «с» и «по»
- Файл скачивается с учётом фильтров

### Кадр 13: Онлайн-отчёты (0:25)
- Вкладка «Сводка» в приложении
- Недельный и месячный отчёты
- Статистика: сколько площадок, обходов, открытых и просроченных замечаний

---

## Часть 5: Мелкие детали (1:00)

### Кадр 14: Пользователи (для админа) (0:30)
- Кнопка «Пользователи» в шапке (только у админа)
- Список пользователей с ролями и районами
- Кнопка «Пригласить» → форма: логин, ФИО, роль, район → создаётся ссылка
- Изменение роли/района существующего пользователя

### Кадр 15: Советы (0:30)
- **Работает офлайн?** Частично — можно смотреть кэшированные данные, но для синхронизации нужен интернет
- **Фото сохраняются?** Да, на сервере. Можно смотреть позже
- **Если забыл пароль?** Обратиться к администратору
- **На телефоне?** Сайт адаптирован под мобильные — можно работать с телефона, фото снимаются сразу через камеру

---

## Титры / Концовка (0:15)
- «Журнал обхода площадок САО»
- «По вопросам обращайтесь к администратору»
- Логотип / контакты

---

## Технические рекомендации для записи:
1. **Разрешение**: 1920×1080 (Full HD)
2. **Запись экрана**: OBS Studio (бесплатно) или встроенная запись Windows (Win+Alt+R)
3. **Микрофон**: любой USB-микрофон или гарнитура
4. **Браузер**: Chrome в режиме инкогнито (чистые куки)
5. **Демо-данные**: заранее подготовить аккаунты инспектора и админа, несколько площадок с обходами
6. **Монтаж**: минимальный — только склейка сцен и титры (Shotcut, DaVinci Resolve — бесплатно)
