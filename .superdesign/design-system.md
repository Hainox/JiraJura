# JiraJura design system

## Product context

A Russian operational system for field inspections of public playgrounds. Primary users are inspectors, district reviewers, and administrators; many are not confident PC users. Statistics must be precise, calm, and self-explanatory.

## Visual foundations

- Font: Century Gothic, Jost, Futura, Trebuchet MS, Arial, sans-serif.
- Header: dark municipal blue. Use the existing blue hierarchy; no gradients.
- Surfaces: white cards on pale slate background, compact blue-grey table borders.
- Primary good: #63BE7B. Primary critical: #E06666. Keep text legible against all status fills.
- Desktop tables remain information-dense but use grouped headers and explicit labels.
- Buttons are clear text labels with familiar icons and visible focus outlines.

## Statistics rules for visible copy

- Always show a percent as the primary value and X из Y as supporting evidence.
- Label the timezone МСК (UTC+3).
- Distinguish За период from Состояние на конец периода.
- A missing denominator is neutral —, never a red 0%.
- Historical reconciliation cards are workflow work, not a grade for district quality.

## Approved percentage colours

Direct good percentage: 0–19 #E06666; 20–39 #F4B183; 40–59 #F9CB9C; 60–74 #FFD966; 75–89 #A9D18E; 90–100 #63BE7B.
For a defect percentage, reverse the scale so 0% is green.

## Interaction

Use 44px minimum tap targets for core actions, plain Russian copy, and never rely on colour without a numeric percent and text label.
